# ArchScope v0.4.0-rc.1

0.4.0 기능 라인을 준비하는 **제한된 평가용 사전 릴리스**입니다.
0.3.5 이후 누적한 진단·Windows HTTP·네이티브 화면 개선을 포함합니다.
전체 원본 도구 동등성이나 모든 운영 환경의 수용 완료를 선언하지 않습니다.

## 다운로드와 버전

| 산출물 | 대상 |
| --- | --- |
| macOS DMG / 앱 ZIP | Apple Silicon arm64, macOS 12 이상 |
| Windows 설치 프로그램 / 실행 파일 ZIP | Windows x64, WebView2 필요 |
| Linux DEB / RPM / 실행 파일 압축 | x64, GTK4·WebKitGTK 6 런타임 |
| archscope-docs.zip | 한국어·영어 매뉴얼, 참조 문서와 저장소 예제 |
| archscope-conformance-v1.zip | 합성 오프라인 적합성 표본 |
| SHA256SUMS | 릴리스 첨부 파일 체크섬 |

앱/About 표시는 **0.4.0-rc.1**, Windows 숫자 파일 버전은 **0.4.0.1**입니다.
macOS 번들 단축 버전은 **0.4.0**, 빌드 번호는 **4001**이며 Linux 패키지는
RC 버전을 사용합니다. x86 검증 기록이 x86 설치 파일 배포를 의미하지 않습니다.

macOS Developer ID·공증 자격 증명이 없으면 워크플로는 ad-hoc 서명을 사용하며
공증은 설정된 자격 증명이 있을 때만 수행합니다. Windows 산출물은 이 워크플로에서
Authenticode 서명하지 않습니다. 오프라인 사용에는 OS 런타임이 미리 필요하며,
일반 Windows 설치 프로그램은 WebView2가 없으면 bootstrap을 사용할 수 있습니다.

## 포함한 작업

- CPU/wall/lock 프로파일, 원본 py-spy/Speedscope/pprof, 공통 drilldown,
  원본 참조와 케이스 기반 baseline 비교.
- 액세스·GC·JFR/native memory·예외·다중 언어 쓰레드 덤프,
  Jennifer MSA·trace·Chrome/V8 CPU·Lighthouse 분석.
- 케이스 저장·검색, 메트릭 이력, 시스템/perf/제한된 BPF, runtime,
  DB/소켓, benchmark/crash, LLM/서빙과 CPU/GPU 근거 흐름.
  생성 도구·버전 지원은 문서에 명시한 실제 검증 입력 범위입니다.
- Windows 명시적 프록시 HTTP/1.x 캡처, HAR 및 지원 세션 형식,
  제한된 보관·프로세스 귀속·검사기·주석·세션 비교/상관과 명시적 전송 Builder.
- 실제 SEC-10 사전 검증이 허용할 때만 가능한 요청/응답 본문 수집.
  기본 꺼짐, 세션별 opt-in, 마스킹·미리보기 상한과 누락/미지원/인코딩/잘림 표시.
- 입력 변경 시 오래된 결과 제거, x86 프로파일 가중치, 실제 단위 차트/CSV,
  결정적인 제한 PowerPoint 요약, 접근성 및 화면별 상세 사용자 매뉴얼.
- 반복 가져오기 보관 개선과 유한 메모리 검증. 과거 증가 실패는 보존하며
  이후 측정창 통과를 모든 부하의 누수 없음으로 확대하지 않습니다.

## 남은 검증

작업표의 **T-601 REVIEW, T-611 REVIEW, T-613 PENDING, T-627 REVIEW,
T-654 TODO, T-662 TODO**를 유지합니다. 이번 RC로 종결하지 않습니다.

- 투명/WinDivert, 프록시 무시 client, service·다른 세션의 실제 캡처 범위는
  해당 백엔드·격리 환경의 네이티브 검증이 더 필요합니다.
- 원 vendor/외부 early-bound COM, 세션 cookie와 clean-host 등록 수명주기는
  이미 확인한 자동화 계약과 별도입니다.
- 원본 V7.6.4 전체 요청·표시·export 동등성, 실제 IME 조합, drag,
  남은 형식/본문 조건, 실제 OS DPI·언어 및 전체 result/provider/keyboard/
  reference 조합은 미완료입니다. WebView 확대는 OS DPI 검증이 아닙니다.
- Windows x64 본문 수집은 실제 preflight 결과에 따라 제한됩니다.
  dump·신뢰·보안 정책을 우회하지 않습니다.
- 메모리 결과는 고정한 부하와 유한 기준의 범위입니다. 고유/본문이 많은 새 입력,
  더 긴 실행, 남은 x86 네이티브 부하, JS heap과 OS private의 귀속,
  실제 Windows 디스크 고갈·전원 손실 복구는 개별 기록 이상을 보장하지 않습니다.
- 실제 2-GPU CUDA/NCCL 분산 추론 및 자연 nonzero-swap/높은 메모리 압력 입력은
  아직 확보되지 않았습니다. CPU/구조 표본이나 관측된 swap 0으로 대체하지 않습니다.
- 기존 독립 리뷰의 CONDITIONAL은 보존합니다. 로컬 수정은 새로운 독립 PASS가 아닙니다.

## 호환성과 검증

기존 AnalysisResult·데이터 계약의 의미를 유지합니다. 앱 사전 릴리스 순서는
SemVer로 비교하고 데이터/adapter/extension 버전은 기존 숫자 계약을 유지합니다.
변경하지 않은 서명 bootstrap 팩은 정식 0.4.0 미만을 허용하므로 이 RC는 포함됩니다.
정식 0.4.0에는 새로 검증한 호환 서명 팩이 필요하며 기존 범위를 임의로 넓히지 않습니다.

릴리스 준비에서는 로컬 전체 Go test/race/vet, 프런트엔드 state/build,
자원·버전 검사와 패키징을 확인합니다. 태그 게시 전 hosted Engine Native,
Windows GUI smoke 및 3개 플랫폼의 패키징을 확인합니다.
이 검사가 남은 네이티브 수용 조합을 대신하지는 않습니다.
