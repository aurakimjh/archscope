# 데스크톱 리본과 표시 언어

데스크톱 앱의 창 안 메뉴는 파일·홈·분석·HTTP·워크스페이스·보기·도움말로
구성된 한 줄 탭입니다. 탭을 선택하면 리본 명령이 즉시 바뀌고, 분석기
명령을 선택하면 도구가 전환됩니다. 리본 탭만 바꿀 때는 현재 페이지와
입력을 유지합니다.

펼친 리본의 명령 아이콘은 24px이며, 일반 데스크톱 너비에서 탭과 명령
영역의 전체 높이는 약 122px입니다. 너비가 1050 CSS px 미만이면 명령
그룹을 팝업으로 묶고, 760 CSS px 미만이면 보조 탭을 선택 목록으로
옮깁니다. macOS의 기존 응용 프로그램 메뉴는 OS 메뉴 막대에 남습니다.
Windows와 Linux는 창 안 리본을 사용하며 창 메뉴 막대를 중복 표시하지
않습니다.

## 표시 상태

- **리본 항상 표시:** 탭과 명령을 계속 표시합니다.
- **탭만 표시:** 탭을 누르면 명령을 임시로 열고, Escape나 바깥 클릭으로
  닫습니다.
- **리본 숨김:** 작은 리본 표시 버튼으로 다시 펼칠 수 있습니다.

탭 오른쪽 표시 옵션, 보기 탭, 탭 두 번 클릭 또는 Ctrl+F1으로 상태를
바꿀 수 있습니다. 선택한 상태는 재실행 후에도 유지합니다. 파일 화면을
열어도 현재 페이지는 유지되며 돌아가기나 Escape로 복귀합니다.
HTTP 명령은 현재 캡처 페이지의 실행 가능 상태에 맞춰 활성화합니다.
리본은 기존 네이티브 메뉴·단축키와 같은 명령 처리 경로를 사용합니다.

## 표시 언어

보기 → 언어 및 설정에서 English(`en`), 한국어(`ko`), 日本語(`ja`),
简体中文(`zh-CN`), 繁體中文（台灣）(`zh-TW`)을 선택할 수 있습니다.
번체는 대만 용어를 기준으로 합니다. 홍콩·마카오의 시스템 언어도 같은
번체 사전을 선택하며 별도의 지역별 번역은 제공하지 않습니다.

저장한 선택이 시스템 언어 목록보다 우선합니다. 중국어는 문자 태그가
지역 태그보다 우선하며 `zh-Hans`는 간체, `zh-Hant`는 번체를 선택합니다.
문자 태그가 없으면 TW/HK/MO는 번체, 나머지 중국어 지역은 간체를
선택합니다. 지원하지 않는 언어는 영어로 표시합니다. 언어는 기존
`archscope.profiler.locale`, 리본 상태는
`archscope.desktop.ribbon.mode`에 저장합니다.

추가한 세 언어의 사전은 각각 고유 원문 2,197개를 포함합니다. 기존 메시지
키, 인라인 UI 문구, 문맥 도움말, 네이티브 메뉴를 번역했습니다. 기술
식별자와 원본 입력·진단 데이터 값은 원문을 유지합니다. Markdown 설명서는
영어와 한국어로 유지하며 일본어·중국어 UI에서는 영어 설명서로 연결합니다.
UI 번역이 입력 데이터나 엔진의 모든 진단 문장 번역을 의미하지는 않습니다.

저장소 루트에서 `python3 scripts/check-desktop-i18n.py`를 실행하면 번역
누락과 치환 변수를 검사합니다. 프런트엔드 상태 테스트는 언어 협상,
메시지 키 일치, 리본 설정 기본값, HTTP 명령 라우팅을 확인합니다. 명시적
네이티브 `layoutaudit` 빌드에서 `ARCHSCOPE_LAYOUT_SCRIPT`로
`scripts/verify-ribbon-native.js`를 지정하고 `ARCHSCOPE_LAYOUT_OUT`으로
결과를 저장할 수 있습니다. 독립 언어 검수와 실제 Windows WebView2의
배율·키보드 검증은 로컬 빌드 및 교차 컴파일과 별개입니다. 확인 범위는
`work_status.md`에 기록합니다.

네이티브 반응형 UI 검증 빌드에서는
`ARCHSCOPE_LAYOUT_VIEWPORT='{"width":1024,"height":768,"zoom":1.25}'`와
`ARCHSCOPE_LAYOUT_MAX_SECONDS=300`으로 창 크기·확대율·검증 제한 시간을
지정할 수 있습니다. 일반 제품 빌드에는 이 옵션이 포함되지 않습니다.
WebView 확대율 변경은 OS 화면 배율 변경과 구분합니다.

### Windows 검증 — 2026-11-16

실제 Windows WebView2 x64/x86에서 5개 언어·6개 리본 탭을 창1280×800/100%,
1024×768/125%,900×768/125%로 검증했습니다. 언어·탭180조합과 테마18선택이
통과했습니다. 실제 OS 배율은100%이며 창 테두리와 확대율을 반영한 CSS 폭은
1264/806/707입니다. 선택 탭·언어·테마 글자 대비는4.5:1 이상으로 확인했습니다.
기존 스타일과 Tailwind가 같은 accent 변수를 다른 뜻으로 사용해1.118:1로
흐리게 표시되던 오류를 수정했습니다. Windows의 Ctrl+,는 Wails의 OEM 문장
부호 키 매핑으로 일치하지 않아, Windows에 한해 렌더러가 논리 단축키를
처리합니다. 다른 플랫폼은 네이티브 소유를 유지합니다. 실제 키 입력으로
양쪽 아키텍처의 설정 이동과 x86의 F1 문맥 도움말·Ctrl+F1 접기를 확인했습니다.

일본어·중국어 스크린샷은 해당 Windows 표시 조건의 글꼴 확인이며 독립 언어
감수나 실제 IME 조합 통과가 아닙니다. 다른 물리 키보드·provider 경로와 전체
실제 OS 배율 조합은 남습니다. 번역 검사기는 UTF-8을 명시해 한국어 Windows의
CP949 기본값에서도 실행되며 일반·최적화 Python 모두 추가 언어별2197문구와
치환 변수 검사를 통과했습니다. T-663/T-664는 REVIEW를 유지합니다. 증거:
docs/review/evidence/2026-11-16-windows-validation/.
